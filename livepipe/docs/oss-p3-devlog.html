两条路径

来源链路落点
直播（dypy 等） 下载器直接写 <root>/<事件>/<日期>/<平台>/<账号>/<名>.mp4.part → 校验 → os.replace → manifest 直播录屏/<事件>/…/<名>.mp4
百度网盘 bypy download 远端目录 → 本地暂存 → 逐文件复制成 OSS .part → 同一套校验/改名/manifest 直播录屏/<dest-rel>/…

live：下载器只负责写 .part，收尾统一做

项行为
命令--cmd 里的 {part} / {final} / {dir} 替换成转义路径；也提供 OSS_PART/OSS_FINAL/OSS_DIR 环境变量。dypy 参数不写死，换下载器只改 --cmd
成功后必须存在 .part；--expect-bytes / --expect-duration 做闸门；默认要求 ffprobe 读到有效时长；改名后写 manifest（字节/时长/事件/日期/平台/账号/来源）
失败命令非 0 → 不留正式文件（下载器违约写了正式名也会删掉）； .part 默认保留续传，--clean-part-on-fail 可删
幂等正式文件已存在且可读 → 直接返回 0，不重跑命令； --clean-part 开始前清旧半成品，--resume 允许续传

baidu：bypy 只拉目录，入库仍走 .part

项行为
下载bypy -v --processes N --on-dup skip download <远端> <暂存>；失败直接返回，不复制任何文件到 OSS
入库只挑视频扩展名；每个文件复制成 <final>.part，核对字节后调用同一套收尾（时长必须可读）
元数据manifest 记 source=baidu:<远端目录> 与 remote_rel
暂存默认保留；--clean-staging 全部成功后删除
落点--dest-rel 直接给 OSS 根下相对目录；不写则用 event/day/platform/account

验收：真实 OSS 写入

测试路径都在 直播录屏/_p3_probe/，验收后已清理。

用例输入结果
3.2GB 直写 3,229,231,923 B 源文件，--cmd "cp <源> {part}"， 期望字节 + 期望时长 12,507.435667s 正式文件生成，字节一致，ffprobe 12,507.4s， manifest 字节/时长一致；直写耗时 536s（约 6.0 MB/s）
百度目录 bypy 下载 /直播录屏/_p3_probe/2026-11-19（1 个测试视频） → OSS _p3_probe/11.19/抖音/test 2,948 B、1.0s，manifest 记录 baidu 来源； 非视频不复制；暂存目录已清理
失败：命令非 0--cmd "echo boom > {part}; exit 3"（真实 OSS） EXIT 1，无正式文件；--clean-part-on-fail 连 .part 一起删
失败：下载器写正式名--cmd "cp 源 {final}; exit 1" 正式文件被删除
失败：字节闸门--expect-bytes 多 1 字节 拒绝收尾，.part 保留
现场观察：3.2GB 单文件直写期间 goofys RSS 约 6.0GB（机器 15GB，验收时剩余可用约 4GB）；写入墙钟 536s，收尾后的可读性用 ffprobe + 中段/末段帧解码验证。小内存机器建议先做 256MB 级别压测，或退回「本地暂存 → 后台上传」的兜底路径。

没有做什么

  • 没有真跑 dypy：本机没有 dypy；3.2GB 直写用 cp 作为 下载器替身，验证的是「下载器写 OSS .part → 收尾」这一段。dypy 的 真实参数以它自己的 --help 为准，只替换 --cmd。
  • 没有把结果/下载接进队列：P3 只做下载与入库；直播排期/队列仍由 dypy 侧负责。
  • 没有保留 3.2GB 测试对象：验收后删除测试文件与 Baidu 临时目录。
  • 没有提交 git：脚本与文档留在工作区。

怎么复现

# 直播：下载器写 {part}，成功后收尾
python3 scripts/oss_download.py live \
  --event 2026-11-20XX --day 11.20 --platform 抖音 --account 奇瑞汽车 \
  --name 10-00-11-16 --cmd 'dypy 直播 <参数> --out {part}'

# 百度：列目录后 PCS 流式直写 OSS（无本地暂存；--resume 续传）
python3 scripts/oss_download.py baidu \
  --remote /直播录屏/10.20上午 \
  --dest-rel 2026-10-20XX/10.20/抖音/奇瑞集团

# 离线自检
python3 scripts/selftest_oss_download.py
