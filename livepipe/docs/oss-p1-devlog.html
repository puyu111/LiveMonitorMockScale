单文件怎么落盘：四步，不留半个文件

步骤动作失败时
1在目标目录写 <名>.mp4.part 清理 .part，重试（最多 3 次，退避 2/4/8s）
2close 后 stat .part，核对字节 == 清单 字节不符即删 .part 重试，绝不 rename
3os.replace(.part → 正式名)（goofys 服务端 rename） —
4再 stat 正式名，核对字节 记失败，保留目标现状供排查

目标已存在且字节相符 → 直接跳过，所以脚本 可以重复跑；目标存在但字节不同 → 拒绝覆盖并报错。本次 24 个上传、5 个试传已在位， 0 失败，没有残留 .part。
